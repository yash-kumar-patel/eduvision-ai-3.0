## ⚡ Quick Project Summary

* **Project Name:** EduVision AI 3.0
* **Domain:** Educational Machine Learning & Multimodal Career Recommendation
* **Target Audience:** Students, Teachers, Parents, and School Administrators
* **Core ML Algorithm:** Gradient Boosting Regressor ($R^2 = 81.38\%$, $\text{MAE} = \pm 1.18$ marks)
* **Dataset:** 395 Verified Student Records (UCI Machine Learning Repository)
* **Tech Stack:** Next.js 14, TypeScript, Tailwind CSS, Three.js (WebGL), Python, Scikit-learn, Vercel
